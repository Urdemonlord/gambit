Gambit is a chess engine in at most 4,096 bytes of Python: alpha-beta search with quiescence, a transposition table and a tapered evaluation, playing the house gauntlet over HTTP.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
